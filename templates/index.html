How ElGamal Works

Beginner-friendly steps used by this tool. Values from your last operation appear in Show Calculations.

1

Key Generation

  1. Select prime p
  2. Select generator g
  3. Select private key x
  4. Calculate y = gx mod p
  5. Public key = (p, g, y)
2

Encryption

  1. Convert the message to a numerical representation m
  2. Select random ephemeral k
  3. Calculate c1 = gk mod p
  4. Calculate c2 = m × yk mod p
  5. Ciphertext = (c1, c2)
3

Decryption

  1. Shared value s = c1x mod p
  2. Modular inverse s−1 mod p
  3. Recover m = c2 × s−1 mod p
  4. Convert the integer back to the original message
4

Files: Confidentiality + Integrity

  1. Confidentiality: hybrid encryption (ElGamal + AES-GCM)
  2. Integrity: SHA-256 of original vs decrypted file
  3. Match → file recovered unchanged
  4. Mismatch → modified or corrupted data

Educational implementation for Information and Network Security. Core ElGamal uses modular exponentiation and the extended Euclidean algorithm — not an ElGamal library.
